# 使い方

画面には説明文を出さない方針のため、操作・入力形式はここにまとめています。短い操作メモは [`USAGE.md`](../USAGE.md) にもあります。

## 基本の流れ
1. 「解析するデータ」で入力方法（URL / テキスト / ファイル / 音声入力）を選んで入力する。複数の方法を同時に使える。
2. 「抽出モード」を選ぶ（高速 / AI抽出 / 統計）。
3. 必要なら「絞り込み・出力設定」を開いて条件を入れる。
4. 「抽出スタート」（PC は `Ctrl+Enter` / Mac は `⌘+Enter`）。
5. 結果から曲を選び、編集・書き出し・セトリ追加を行う。

## 入力方法
| 方法 | 内容 | キー |
|---|---|---|
| URL | YouTube 動画・プレイリスト、SoundCloud、ランキングページ。改行で複数（30件まで） | 不要（プレイリスト全件・再生数は YouTube API キーがあると確実） |
| テキスト | 曲リストを貼り付け（30万文字まで） | 不要 |
| ファイル | CSV / TSV / テキスト / Excel（xlsx・xls・ods）は不要。PDF・画像は AI キーが必要。合計 4MB・10 ファイルまで | PDF・画像のみ AI |
| 音声入力 | 日本語。認識結果はテキスト欄に1行ずつ追記される | 不要 |

### テキストで読み取れる書き方
1行に1曲。次のような形式を自動で読み取ります（全角・半角どちらでも可）。

```
1位 ロキ / みきとP feat. 鏡音リン
２．千本桜　／　黒うさP
DECO*27 - ヴァンパイア feat. 初音ミク
【初音ミク】メルト【オリジナル】
千本桜 https://youtu.be/dQw4w9WgXcQ
```

- 先頭の順位（`1位` `01.` `#3` `No.5` `①` `第12位`）は取り除かれる。
- `曲名 / P名`（`／` も可）、`P名 - 曲名`、`feat.` / `ft.`（歌唱者）、`【歌唱者】` を解釈する。
- URL が書かれていれば、その曲の動画 URL として使う（URL だけの行は無視）。
- CSV / TSV（Excel から貼り付け）は「曲名, P名」または「順位, 曲名, P名」の列として読む。`"Hello, World",Foo` のように引用符で囲めばカンマを含む曲名も使える。見出し行（`曲名` `順位` `title` `rank` で始まる行）は読み飛ばす。
- 改行コードは CRLF（Windows）・LF（Mac/Linux）・CR のみ（旧 Mac）のどれでもよい。
- 半角カナは全角に、全角英数記号は半角にそろえ、ゼロ幅文字は取り除く。
- `!!!` `♪♪♪` のような記号だけの曲名も1曲として残す（記号違いは別の曲）。
- 区切り線（`=====` `-----` など）や 2000 文字を超える行は、曲の行ではないとして読み飛ばす。

## 抽出モード
| モード | 必要なキー | 内容 |
|---|---|---|
| 高速 | なし | 規則ベースで曲名・P名・歌唱者を判定 |
| AI抽出 | Gemini または OpenAI | 資料全体（Web ページ・PDF・画像を含む）を AI が解析。BPM / Key / MMD / テーマ判定 |
| 統計 | YouTube Data API | 再生数・コメント数で絞り込み |

- AI エンジンは「おまかせ」で Gemini を優先し、失敗したら ChatGPT に自動で切り替える。
- 「MMD がある曲のみ」と「テーマ」は AI の知識で判定する（AI 抽出モード推奨）。
- 除外ワードは、曲名・P名・歌唱者のどれかに含まれると除外する（カンマ・読点区切りで複数）。

## 絞り込み条件
再生数・コメント数の範囲、除外ワード、ボカロ・P の指定、BPM（±3 を許容）、Key（`Am` / `8A` / `A minor` は同じ扱い）、複数人歌唱のみ、MMD ありのみ。数値欄は全角数字・カンマ付きでも入力できる。

## 結果の操作
- **編集**: 各曲の「編集」で曲名・P名・合成音声・BPM・Key・MMD・動画 URL を補正できる。保存すると書き出し・履歴に反映される。URL を別の動画に変えると再生数などは未取得に戻る。
- **選択**: チェックした曲があればその曲、無ければ表示中の曲が書き出し・セトリ追加の対象。「ランダムに N 曲」で抽選も可。
- **並べ替え・検索**: 結果の上部。演奏済みリストに載っている曲にはバッジが付き、隠せる。
- **統計**: ボカロ別・P別の曲数、BPM 分布、MMD 比率。
- **書き出し**: Excel / CSV / クリップボード（Excel・スプレッドシートへ貼り付け用）/ 画像 / PDF（印刷）/ M3U8 / rekordbox XML / YouTube 連続再生（50曲ごとに分割）。
- Excel・CSV・コピーでは、セルの先頭が `=` `+` `-` `@` のとき先頭に `'` を付け、数式として実行されないようにする。

## セトリ（公演の進行表）
- テンプレート（定番・ミニライブ・フル・空）から作成。抽出結果から追加すると、空きの曲枠が先に埋まる。
- 長さは `4:00` `3分30秒` `240s` `4`（=4分）のように入力できる。開始時刻を入れると各項目の開始を時計で表示する。
- BPM・Key（Camelot 表記）の流れ、重複・演奏済みの警告を表示。テキスト / TSV / Excel / JSON で書き出せる。
- 演奏済みリストは「曲名 / P名」を1行に1曲（番号・箇条書き・`（BPM 150）`・`4:00`・`※メモ` は取り除かれる）。曲名だけで照合する。

## タブ（プリセット）
入力内容・設定・結果をタブごとに保持（最大 10 個）。ダブルクリックまたは `F2` で名前変更、ドラッグで並べ替え、`×` / `Delete` / ホイールクリックで閉じる（直後は「元に戻す」）。共有ボタンのリンクには入力内容と設定が入り、API キーは入らない。

## データの保存とバックアップ
- プリセット・履歴（最新 20 件）・セトリ・演奏済みリスト・設定はこの端末のブラウザに自動保存される。
- API キーは既定では保存せず、タブを閉じると消える（設定で「この端末にキーを保存する」を選んだときだけ保存）。共用 PC では保存しないこと。
- 別の端末へはバックアップ（JSON）で移す。復元は今のデータに追加される。キーは含まれない。

## スマホ（iPhone / Android）
- 下部の操作バーで画面を切り替える。共有メニューの「ホーム画面に追加」でアプリのように起動できる（PWA）。
- 音声入力は HTTPS・ブラウザのマイク許可・対応ブラウザが必要。使えないときは OS キーボードの音声入力を使う。
